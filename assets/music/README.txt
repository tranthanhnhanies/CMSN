Thư mục này dùng để chứa file nhạc nền sinh nhật (tên file: birthday.mp3).

Cách thay nhạc:
1. Chuẩn bị 1 file âm thanh định dạng .mp3 (khuyên dùng nhạc piano, lofi, acoustic hoặc giai điệu nhẹ nhàng).
2. Đổi tên file thành: birthday.mp3
3. Copy hoặc lưu file vào thư mục này: public/assets/music/birthday.mp3

Lưu ý:
- Nếu bạn chưa có file birthday.mp3, website đã tích hợp sẵn một bộ phát giai điệu Music Box (Hộp nhạc cổ điển) êm dịu bằng Web Audio API, nên khi nhấn nút 🎵 website vẫn có nhạc du dương ngay lập tức!
